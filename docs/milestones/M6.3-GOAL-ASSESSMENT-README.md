# M6.3 Goal Assessment & Goal Guidance

## Goal assessment model

A goal is assessed using the number of meaningful achievements that have both:

1. supporting evidence, and
2. demonstrated impact linked through the evidence ID.

The current M6.3 expectation is a minimum of **3 qualifying achievements per goal**.

- **Not Met Expectations:** fewer than 3 qualifying achievements
- **Met Expectations:** exactly 3 qualifying achievements
- **Above Expectations:** 4 or more qualifying achievements

The displayed expectation ratio is transparent: 3/3 = 100%, 4/3 = 133%, 5/3 = 167%, etc. The visual progress bar remains capped at 100% so it does not overflow.

## Goal guidance

Goal Detail now provides a **Getting Started / Keep Building** guidance experience when the goal has not yet reached the expected threshold.

For a goal with no activity, the page explains the recommended journey:

1. Choose a concrete outcome.
2. Capture the achievement and supporting evidence.
3. Demonstrate the difference it made.
4. Repeat until three demonstrated achievements are reached.

The guidance uses the same Achievement → Evidence → Impact model as the assessment. It does not invent goal-specific work or pretend that an action was completed.

When evidence exists but impact has not been demonstrated, the guidance shifts toward converting the existing work into demonstrated impact.

## Product direction

M6.3 owns the basic goal guidance and expectation experience. Future M6.7 AI Assistant work can make the guidance dynamic using the user's role, goal content, previous achievements, knowledge, and available evidence.

## Achievement → Evidence → Impact

Each achievement is displayed together with its linked impact assessment(s). An achievement without demonstrated impact is explicitly shown as an evidence/impact gap rather than being treated as completed impact.

## Scope

This change is frontend-only. No backend API contract changes are required.
