# M6.3 CSS Structure Update

Restores the approved M6.2 Dashboard presentation while keeping page-specific CSS isolated.

- `src/styles/global.css` — shared application shell and reusable primitives
- `src/pages/Dashboard/Dashboard.css` — Dashboard-only styling
- `src/pages/Goals/Goals.css` — Goals page styling
- `src/pages/Goals/GoalDetail.css` — Goal detail styling

`main.tsx` loads `global.css`, and each page imports its own stylesheet. The legacy `src/styles.css` is no longer imported.
