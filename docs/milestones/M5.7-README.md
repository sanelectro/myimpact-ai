# M5.7 — API Integration Tests (Corrected)

## Scope

M5.7 validates the complete product-facing API surface delivered through M5.1–M5.6.

## Corrections

- Removed `/api/v1/me` and `/api/v1/me/goals` from the integration-test route inventory because those endpoints have not been implemented in M5.
- Standardized v1 HTTP errors to always include `details`.
- Normalized Pydantic/FastAPI validation error context values to strings so `ValueError` instances cannot break JSON serialization.

## Production impact

Only `app/api/v1/errors.py` changes production behavior, and only for the existing v1 error contract. No database or domain-model changes.
