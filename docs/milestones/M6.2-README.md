# MyImpact — M6.2 Dashboard

## Milestone overview

**Milestone:** M6.2  
**Status:** Validated on 24 October 2026 against the current implementation.

M6.2 provides a dashboard that helps users understand progress across goals and their role/career journey without duplicating the detailed goal experience.

## Objectives

- Summarize progress across the user's goals and milestones.
- Surface useful evidence and impact indicators.
- Make assessment strength and progress understandable at a glance.
- Provide a useful experience for new users and users with partially completed goals.
- Keep dashboard content concise and link users to goal detail for supporting information.

## Product rules

- A qualifying achievement requires an achievement, supporting evidence, and demonstrated impact.
- Goal assessment states are `NOT_STARTED`, `IN_PROGRESS`, `MET_EXPECTATIONS`, and `ABOVE_EXPECTATIONS`.
- Goal progress is qualifying achievements divided by the target of three. The displayed percentage may exceed 100%; a visual progress bar must be capped at 100%.
- Aggregate dashboard progress may be capped at 100%.
- The dashboard must use the same assessment and progress rules as goal list and detail views.

## Acceptance checks

- Validate dashboard API calls against the current backend.
- Check new-user, empty, partially completed, and completed-goal states.
- Verify assessment and aggregate calculations against the product rules.
- Confirm responsive layout, loading/error behavior, and API failure handling.
- Avoid duplicating goal-detail content or showing redundant progress/impact summaries.

## Validation status

The combined M6.1–M6.5 Playwright run passed the M6.2 empty-user, partial
progress, over-100% goal progress, and API-error scenarios. Frontend build and
unit tests also passed. The full integrated release flow remains part of M6.8.
