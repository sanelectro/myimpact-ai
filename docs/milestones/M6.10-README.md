# MyImpact — M6.10 End-to-End UX Validation

## Milestone overview

**Milestone:** M6.10  
**Status:** Not confirmed complete.

M6.10 validates the integrated user journeys across committed M6 scope. It
records test evidence and unresolved integration defects; release deployment
and go/no-go decisions are handled separately in M7.

## Integrated journey

Validate the connected user flows across authentication, organization setup,
goals and documents, evidence capture, M6.6 goal assessment, M6.7 Impact
Analysis, M6.8 reports, and M6.9 admin operations.

## Acceptance checklist

- [ ] Run agreed backend, frontend, integration, and browser suites against
  current source.
- [ ] Validate end-to-end user journeys for goal creation/import, evidence
  association, assessment, Impact Analysis, and reports.
- [ ] Validate registration, sign-in, protected API access, organization
  profile, and admin workflows.
- [ ] Verify representative no-data, partial-data, error/retry, and
  authorization paths.
- [ ] Verify cross-user and cross-organization isolation across the integrated
  journeys.
- [ ] Verify the UI presents consistent goal/progress information across
  dashboard, Goals, and assessment views.
- [ ] Record environment, exact commands, scenarios, results, and unresolved
  integration defects.

## Boundaries

- M6.10 is a validation milestone; it does not add new product features.
- Deployment, production operations, documentation readiness, and release
  go/no-go are covered by M7.
- A milestone is not considered validated based only on existing test results
  or implementation files; rerun relevant checks against the current source.
