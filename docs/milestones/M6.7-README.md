# MyImpact — M6.7 Impact Analysis

## Milestone overview

**Milestone:** M6.7  
**Status:** Planning proposal; acceptance criteria and implementation are not confirmed complete.

M6.7 adds a separate, employee-facing Impact Analysis experience on top of
validated M6.6 goal-criterion assessments. It summarizes source-linked progress
and cross-goal patterns; it does not create evidence, alter goals, or replace
criterion-level assessment.

## Proposed scope

- Provide a monthly view of progress and demonstrated impact across the user's
  goals, using the reporting-period boundaries and sources visibly.
- Summarize validated criterion assessments and their authorized, linked
  evidence; distinguish source facts from generated explanations.
- Preserve whether evidence is unreviewed or manager-accepted, and distinguish
  AI-assessed results from employee-confirmed or manager-reviewed outcomes.
- Include only assessments for the current criterion version in current
  summaries; surface stale or obsolete history without treating it as current.
- Surface evidence gaps, uncertainty, stale assessments, and out-of-period
  sources instead of filling gaps with unsupported claims.
- Reuse M6.6 assessment, evidence eligibility, authorization, and freshness
  rules. Do not create a second evidence store or independent scoring system.
- Keep results employee-scoped. Manager sharing, organization-wide analytics,
  performance ratings, and predictive decisions are outside this proposal.

## Acceptance criteria

- [ ] Users can view source-linked analysis for the supported reporting period.
- [ ] Every factual conclusion can be traced to the goal assessment and
  evidence that supports it.
- [ ] Results distinguish source facts, deterministic aggregation, and any
  AI-generated narrative.
- [ ] Empty, weakly supported, stale, and out-of-period data are handled
  explicitly without inventing accomplishments or implying performance ratings.
- [ ] The experience enforces the same owner and evidence-access boundaries as
  M6.6.
- [ ] The analysis does not modify goals, criteria, evidence, or assessments.
- [ ] API/service, UI, integration, and end-to-end tests cover period filtering,
  source traceability, authorization, uncertainty, and failure behavior.

## Decisions to resolve before implementation

- Confirm whether the initial analysis is monthly only or supports custom
  periods.
- Define which aggregate views and summaries are needed without adding
  unapproved weights or performance scores.
- Decide whether generated narrative is required or whether source-linked
  structured summaries are sufficient.
- Define freshness behavior when underlying assessments or evidence change.
- Confirm whether any sharing is in scope; default to private, owner-scoped
  results.

## Dependency

M6.7 depends on M6.6's validated, source-linked goal assessments and confirmed
evidence eligibility/freshness rules.
