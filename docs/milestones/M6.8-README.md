# MyImpact — M6.8 1:1 and Career Reports

## Milestone overview

**Milestone:** M6.8  
**Status:** Planned; acceptance criteria and implementation are not confirmed complete.

M6.8 turns M6.6 goal assessments and M6.7 Impact Analysis into private,
reviewable employee-facing 1:1 briefs and career reports. A report is a
user-controlled summary, not new evidence and not an automatic manager feed.

## 1:1 preparation

- Let the user select a date range, defaulting to the current month.
- Prepare a concise brief with expectations and progress, completed goals as
  achievements, active goal/milestone progress, evidence awaiting review,
  blockers, evidence gaps, suggested next contributions, and discussion topics
  or asks.
- Let the user edit the brief and add private notes/questions. Clearly
  distinguish user-authored text and AI suggestions from linked MyImpact facts.
- Save a user-owned draft that can be revisited. Sharing is a deliberate user
  action; creating or saving a brief does not notify or grant access to a
  manager.

## Career reports

- Start with a quarterly impact/career summary; custom periods may follow.
- Generate a structured, reviewable draft from completed goals, in-period goal
  progress, linked evidence, and validated M6.6/M6.7 results.
- Include the reporting-period boundaries, generation date, source dates, and
  traceable references for factual claims.
- Let the user review, correct, remove, or add content before a deliberate
  print/export action.
- Save and revisit drafts without changing source goals, evidence, or
  assessments. Make source changes and stale content visible.

## Access and trust boundaries

- Drafts and private notes are owner-scoped by default.
- Manager evidence-review access does not grant access to 1:1 notes or career
  reports.
- Sharing or export is an explicit user action with clearly defined access and
  retention behavior.
- Omit or flag unsupported claims. Distinguish source facts, generated
  suggestions, and user-authored edits.
- Scheduling, automatic delivery, performance ratings, calibration, and
  predictive promotion recommendations are out of scope unless explicitly
  approved.

## Acceptance criteria

- [ ] Users can create, edit, save, and revisit a monthly 1:1 brief and
  period-based career report.
- [ ] Briefs and reports use the selected period and disclose period/source
  dates.
- [ ] Completed goals are represented as achievements without creating
  duplicate achievement records.
- [ ] Factual claims link to authorized source context; unsupported claims are
  omitted or flagged.
- [ ] Private notes and saved drafts are protected from manager and
  cross-user access.
- [ ] Sharing and export are user-initiated and follow the approved access and
  retention rules.
- [ ] Edits do not rewrite source evidence, goals, or assessments; stale drafts
  are identified when source data changes.
- [ ] Empty, incomplete, and out-of-period data are handled explicitly.
- [ ] API/service, UI, and end-to-end tests cover period selection, editing,
  persistence, traceability, privacy, and export behavior.

## Decisions to resolve before implementation

- Confirm first-release report types, sections, period defaults, and whether
  regenerated reports retain prior versions.
- Define structured report state, source snapshots, and stale-content behavior.
- Decide whether sharing is in scope; otherwise keep drafts private and support
  only an explicit user-controlled export.
- Choose the first export format and retention behavior.
- Define handling for incomplete periods and unsupported source data.

## Dependency

M6.8 depends on validated M6.6 assessments and M6.7 analysis outputs, while
preserving their source references and access boundaries.
