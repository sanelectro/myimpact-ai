# MyImpact — M6.3 Goals and Expectations

## Milestone overview

**Milestone:** M6.3  
**Status:** Validated against the current implementation on 24 October 2026.

M6.3 delivers goal management, lifecycle controls, transparent assessment, and a document-based goal import flow.

## Scope

- Create, edit, list, and view goals.
- Support goal scopes: `PERSONAL`, `TEAM`, and `ORGANIZATION`.
- Keep goal lifecycle status separate from calculated achievement assessment.
- Import goals from supported documents as editable drafts.
- Preserve source-document provenance and prevent repeat/duplicate imports.
- Require user review and explicit approval before an imported goal is activated.

## Goal lifecycle and assessment

Lifecycle transitions follow:

```text
DRAFT → APPROVED → ACTIVE → COMPLETED → ARCHIVED
```

Operational sub-status is separate from lifecycle and assessment. A qualifying achievement requires all of:

1. An achievement.
2. Active supporting evidence.
3. Demonstrated impact linked through that evidence.

| Qualifying achievements | Assessment |
|---:|---|
| 0 | `NOT_STARTED` |
| 1–2 | `IN_PROGRESS` |
| 3 | `MET_EXPECTATIONS` |
| 4 or more | `ABOVE_EXPECTATIONS` |

Progress is qualifying achievements divided by the target of three. The percentage may exceed 100%; cap only the visual progress bar.

## Import behavior

- Reuse document ingestion and extraction capabilities.
- Create extracted goals as `DRAFT`; allow review and correction before approval.
- Track the source document on imported goals.
- Reprocessing the same source is intended to be idempotent.
- Cross-document duplicate detection is lexical, not semantic. Different synonym phrasing may still be missed.
- Clearly report imported goals, skipped duplicates, empty extraction, and upload failures.
