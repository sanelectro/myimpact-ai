# MyImpact — M6.4 Source Documents and Evidence

## Milestone overview

**Milestone:** M6.4  
**Status:** Goal/document ingestion validated against the current implementation on 24 October 2026.

M6.4 establishes the user-facing flow for ingesting goal documents, reviewing extracted goals, retaining provenance, and making source material usable in later evidence workflows.

## Scope

- Accept supported goal-source documents through existing or justified API contracts.
- Reuse the existing document processing pipeline where appropriate.
- Preserve a secure source document or reference and relevant metadata.
- Extract goal details, dates, and scope where available.
- Present extracted goals as editable drafts; do not activate them automatically.
- Track processing status and actionable failures.
- Make ingestion repeatable without duplicate goal creation.
- Preserve ownership and authorization boundaries.

## Validation recorded

The combined M6.1–M6.5 Playwright run passed a live-stack DOCX upload and
extraction using the configured provider. It verified document provenance,
dates and scope, repeat-import idempotency, editable draft review, explicit
approval, and activation. The full backend suite also passed, including
document parsing, extraction, authorization, and import integrations.

The M6.4 boundary is goal/document ingestion. Goal- and milestone-level
evidence association is covered by M6.5; manager review and impact scoring
remain later milestone scope.

## Acceptance checks

- Verify supported file types, size boundaries, parsing, and failure handling.
- Confirm extracted content and metadata are persisted with provenance.
- Verify evidence can be reviewed and linked to the intended goal/achievement.
- Ensure evidence is not treated as qualifying impact without the required relationships.
- Test repeated ingestion, malformed documents, empty extraction, and authorization isolation.
- Run representative integration tests and confirm current database migrations.
