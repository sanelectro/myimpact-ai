# M5.4 — Evidence + Impact APIs

M5.4 exposes the M4 evidence and impact capabilities through product-facing v1 APIs.

## APIs

- `GET /api/v1/goals/{goal_id}/evidence`
- `POST /api/v1/goals/{goal_id}/impact/analyze`
- `GET /api/v1/goals/{goal_id}/impact`

Impact analysis accepts document IDs because M4 expectations remain document-scoped; M5.4 does not invent a persistent goal-to-expectation relationship.

The API hides internal evidence mappings, embedding/vector details, LLM prompts, and pipeline implementation details.

No database migrations or new persistent models are introduced.
