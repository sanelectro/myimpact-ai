# M5.5 — Career Insight + Report APIs

M5.5 exposes the M4.6 career insight synthesis through product-facing v1 APIs and provides a product-safe goal impact report contract.

## APIs

- `GET /api/v1/goals/{goal_id}/insight`
- `GET /api/v1/goals/{goal_id}/report`

## Flow

```text
Goal + persisted ImpactAssessments
              ↓
       CareerInsightService
              ↓
        CareerInsight
              ↓
     Product Insight / Report
```

The API enforces goal ownership and does not expose LLM prompts, persistence internals, or repository details.

The report is a generated product-facing view of the current goal impact insight; M5.5 does not introduce a new persisted report-to-goal relationship.

No database migrations are introduced.
