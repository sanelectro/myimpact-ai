# MyImpact — M6.9 AI Assistant

## Milestone overview

**Milestone:** M6.9  
**Status:** Planned; use cases, grounding requirements, and implementation are not confirmed complete.

M6.9 is intended to help users understand goals, identify evidence gaps, and improve goal and evidence descriptions. Impact analysis is covered by M6.6; 1:1 preparation and career reports are covered by M6.7.

The existing authenticated `/chat` endpoint in [`app/main.py`](../../app/main.py) forwards the user's message to the configured LLM. That endpoint is not by itself the grounded, source-linked assistant described by this milestone.

## Intended use cases

- Explain goal state and available supporting information.
- Help identify missing evidence without treating gaps as facts.
- Help users improve descriptions while preserving their meaning.

## Work and acceptance criteria

- Define supported use cases, boundaries, and non-goals.
- Ground responses in the current user's authorized data.
- Link responses to relevant goals, evidence, or documents where possible.
- Ask for clarification when information is missing rather than inventing details.
- Define usage/token tracking and AI ON/OFF behavior if required.
- Handle timeouts, provider errors, empty retrieval, and low-confidence results.
- Test authorization and prevent cross-user data exposure.
- Evaluate factuality, relevance, and safe failure behavior.

## Boundaries

The assistant must not replace source review or make unsupported performance judgments. Any generated statement about a user's work should be traceable to authorized source data and clearly distinguish source facts from generated guidance.
