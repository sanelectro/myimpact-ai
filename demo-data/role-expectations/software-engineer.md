# Software Engineer

## Role focus

Deliver software that meets user and business needs by combining sound
implementation, collaboration, and continuous improvement.

## Responsibilities

- Analyze problems and implement clean, maintainable, tested, and secure code.
- Contribute to feature planning and estimation; meet agreed delivery and quality
  expectations and surface risks early.
- Work with engineers, product managers, designers, and other teams to clarify
  requirements and communicate progress.
- Participate in code reviews, resolve defects, and consider performance,
  security, and reliability.
- Improve the codebase through appropriate refactoring and optimization while
  adapting to evolving tools and technologies.
- Maintain technical documentation and share useful knowledge with the team.

## Suggested starter goals

- **Deliver maintainable and secure features:** Implement agreed product
  functionality with appropriate tests and review.
- **Improve delivery planning and collaboration:** Contribute to estimates,
  communicate progress and risks, and align implementation with user needs.
- **Strengthen software quality and reliability:** Resolve relevant defects and
  improve testing, documentation, performance, or security in owned components.
