# Career-path guidance

This document captures career-development guidance. It is not a role
description and does not define role-specific seed goals.

## Guidance

- Discuss career interests and development plans with a manager; agree on work
  that builds relevant capabilities and ask colleagues for feedback.
- Growth can be lateral as well as vertical. Developing skills does not
  guarantee promotion; opportunities and role scope also matter.
- Role expectations can vary between teams, so align the interpretation with
  the manager and team.

The career catalogue includes Software Engineer, Senior Software Engineer,
Lead Software Engineer, Principal Software Engineer, Associate Software
Engineer, Intern Software Engineer, Lead UX Designer, and Lead Solution
Architect. Detailed responsibilities and starter goals for Lead Solution
Architect are not included in this directory.
