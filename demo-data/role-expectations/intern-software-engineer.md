# Intern Software Engineer

## Role focus

Learn how a professional software team works and contribute to meaningful,
well-scoped work with guidance. Curiosity, initiative, and steady growth are
central to the internship.

## Responsibilities

- Build foundational coding skills and apply examples and direction to
  well-defined tasks.
- Learn the software delivery lifecycle, version control, Agile practices, and
  how work moves from planning through release.
- Contribute to coding, bug fixing, testing, documentation, research, or support
  tasks; ask for help early when blocked.
- Practice debugging, logging, team coding conventions, and basic testing.
- Communicate progress and challenges, participate in reviews and team
  discussions, and use feedback to improve.
- Document work and share learnings with the team.

## Suggested starter goals

- **Contribute to a scoped engineering task:** Complete an assigned development,
  bug-fix, or support task with guidance and communicate blockers early.
- **Practice testing and debugging fundamentals:** Add basic tests to assigned
  work and use team tools and conventions to investigate simple issues.
- **Document internship learning:** Record how assigned work moves through the
  team's development process and share useful learnings with teammates.
