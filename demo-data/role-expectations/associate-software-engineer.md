# Associate Software Engineer

## Role focus

Build a strong software-development foundation and contribute to team outcomes
through smaller tasks completed with support and feedback.

## Responsibilities

- Write simple, maintainable code with the team's languages, tools, and
  frameworks; seek guidance on well-defined problems.
- Complete assigned work on time and to agreed quality standards, raising
  challenges when they arise.
- Learn testing, debugging, version control, coding conventions, and other
  engineering best practices from experienced teammates.
- Collaborate with engineers, testers, and product managers; communicate
  progress and participate in code reviews.
- Document solutions, processes, and learnings that can help the team.
- Seek mentorship and apply constructive feedback to ongoing development.

## Suggested starter goals

- **Deliver scoped engineering tasks reliably:** Complete assigned components
  with appropriate guidance, quality, and timely communication.
- **Strengthen code quality and testing habits:** Apply team conventions, write
  basic tests, and use review feedback to improve submitted work.
- **Grow technical capability and team knowledge:** Seek mentorship, build
  familiarity with the team's tools, and document useful learnings.
